## 1. 프로젝트 개요

- **장르:** 모바일 가로형(landscape) 랜덤 디펜스. 한국사 위인(삼국·고려·조선)이 유닛.
- **플랫폼:** 폰 가로 화면 (기준 844×390pt). 개발은 Flutter + Flame.
- **보드 기준 해상도:** 게임 보드 **1560×720px** (폰 화면 pt의 약 1.85배). 아래 모든 "보드 위 크기"는 이 기준.
- **핵심 진행:** 몬스터가 오른쪽 위 출현 지점에서 나와 가로로 긴 육각형 길을 시계 방향으로 계속 돈다. 플레이어는 길 밖 아무 곳에나 유닛을 자유 배치하고, 유닛은 자기 사거리 안을 지나는 몬스터만 공격한다. 필드 몬스터 100마리 초과 또는 보스를 10초 안에 못 잡으면 패배.

## 2. 반드시 지킬 규칙

1. **유아틱하지 않은 그림체.** 귀여운 SD(2~2.5등신)는 피하고 3~4등신의 단단한 실루엣. 진지하지만 모바일에서 읽히는 굵은 외곽선.
2. **실존 위인 표현:** 표준영정, 특정 드라마·영화·게임 캐릭터 디자인을 참고하거나 닮게 그리지 않는다. 얼굴은 창작하되 시대 복식·무기는 고증에 맞춘다(삼국: 찰갑·환두대도, 고려: 고려 갑주, 조선: 두정갑·전립·환도·각궁 등). 확실하지 않으면 "고증 확인 필요"라고 표시.
   - 특히 **이순신·세종·이성계**는 표준영정이 널리 알려져 있으므로 얼굴형·수염·관모 배치가 영정과 겹치지 않게 한다.
3. **44pt 규칙:** 폰에서 유닛은 약 40~45pt로 보인다. 이 크기에서 **병과(무기 실루엣)·등급(테두리·장식)** 이 한눈에 구분돼야 한다. 세부 묘사보다 실루엣 우선.
   - 몬스터(일반 40×44px ≈ 폰 22pt)는 더 작으므로 **실루엣과 명암 대비를 유닛보다 강하게** 한다. 걷기 동작은 몸 전체의 들썩임·다리 실루엣으로 읽히게.
4. **방향:** 모든 유닛·몬스터 기본 그림은 **오른쪽을 본다.** 왼쪽을 봐야 할 때는 게임에서 앵커(하단 중앙) 기준 좌우 반전(scaleX −1)으로 쓰고, 왼쪽용 그림은 따로 만들지 않는다.
   - 반전 시 투사체 발사 지점은 `x' = 프레임 너비 − x`로 바꿔 쓴다.
   - 반전돼도 어색하지 않게: 글자·문양은 좌우 대칭으로, 왼쪽/오른쪽 손이 중요한 소품은 피한다. 건물·맵·이펙트 글자는 반전하지 않는다.
5. **배경 투명**, 발밑 기준점(앵커)은 **하단 중앙**. (예외: 기병은 말 발굽 사이 중앙)
6. **제작 방식 — 컷아웃 리깅:** 그림은 코드(SVG)로 만든다. 캐릭터는 프레임마다 새로 그리지 말고 **머리·몸통·팔·다리·무기·망토를 파츠(그룹)로 나눠** 변환(이동·회전)으로 움직인다.
   - **군졸~장수(3·4단계)**: 0단계 공통 파츠 구조를 그대로 쓰고 색·모자·무기만 바꾼다.
   - **위인(명장·천명·공신, 5~7단계)**: 인물마다 **개별 모델링**. 얼굴·체형·복식·무기를 각자 새로 디자인하고, 파츠 구조도 인물에 맞게 따로 정한다(그림체 규칙 — 팔레트 방식·선 굵기·광원·셀 셰이딩 — 만 공통).
7. **산출물 형식:**
   - 원본: **SVG** (레이어/그룹 id 정리, 파츠 단위)
   - 내보내기: **PNG @2x** (보드 위 크기의 2배 = 폰 pt의 약 3.7배). 원본 SVG가 있으므로 필요하면 나중에 다시 뽑는다.
   - 애니메이션: **스프라이트 시트 PNG + 프레임 JSON** (형식은 아래 7-1)
   - 파일 이름: 영문 소문자 + 하이픈. 예: `unit-spear-jangsu-idle.png`, `mob-boar-walk.png`
   - 7-1. **프레임 JSON 형식:** TexturePacker JSON(Hash) 호환 + 확장 필드
     ```json
     {
       "frames": {
         "unit-spear-jangsu-attack-0": {
           "frame": {"x":0,"y":0,"w":144,"h":168},
           "duration": 80,
           "anchor": {"x":0.5,"y":1.0},
           "events": {"projectile": {"x":118,"y":62}}
         }
       },
       "animations": {"attack": ["unit-spear-jangsu-attack-0", "..."]},
       "meta": {"image":"unit-spear-jangsu-attack.png","size":{"w":864,"h":168},"scale":"2","fps":12}
     }
     ```
     `events.projectile`은 투사체·이펙트가 나오는 프레임에만 넣는다(좌표는 프레임 안 픽셀).
8. **재생 속도(fps) 기본값:** 대기 6 · 걷기 10 · 공격 12 · 시전 10 · 등장/진화 연출 12 · 쓰러짐 10 · 이펙트 15. 동작마다 필요하면 프레임별 `duration`으로 조정.
9. **일관성:** 0단계에서 정한 팔레트·선 굵기·광원(왼쪽 위)·그림자 규칙을 끝까지 유지.
10. 각 묶음 끝에 **한 화면 미리보기(시트 전체를 실제 보드 크기로 축소)** 와 **폰 실제 크기(보드 ÷ 1.85) 미리보기**를 함께 보여준다.
11. **작업 분량 나누기:** 각 단계는 **단계 전체를 한 번에** 만들어 확인받는다(병과별로 나눠 보여주지 않음). 새 묶음을 시작할 때마다 0단계 스타일 가이드(팔레트·선 굵기·파츠 구조)를 다시 확인하고 시작한다.

## 4. 제작 단계

### 0단계 — 스타일 가이드 (먼저 확정)
- 그림체 시안 **3가지** (SVG로 현실적인 범위): 예) ① 플랫 + 굵은 외곽선 ② 2단 셀 셰이딩 ③ 판화/목판풍. 같은 유닛(창병 장수)과 같은 몬스터(멧돼지)로 비교.
- 각 시안에 팔레트, 선 굵기, 명암 단계, 외곽선 규칙을 정리한 한 장짜리 가이드.
- **파츠 구조(컷아웃 리깅) 도면**: 파츠 이름, 관절 위치, 그리기 순서.
- 위 "등급 구분" 표를 실제 크기로 그린 견본 한 줄(군졸~천명).
- 실제 보드 크기(유닛 72×84px, 몬스터 40×44px)와 폰 크기로 줄인 미리보기 포함.
- **내가 하나를 고르면** 그 스타일로 다음 단계를 진행.

### 1단계 — 맵
- **배경:** 풀밭 타일(반복 가능 512×512), 작은 풀·돌·꽃 장식 스프라이트 6~8종, 나무 3종, 소나무 2종 (보드 위 나무 약 60×70px).
- **길:** 9-slice는 쓰지 않는다(모서리가 직각이 아니라서 이어 붙지 않음). 대신:
  - 길 전체를 **1404×720 레이어 한 장**(외곽·흙·밝은 흙·바퀴 자국 점선)으로 그린다.
  - 같은 중심선 좌표를 **경로 JSON**(점 목록 + 전체 길이)으로 함께 낸다. 게임은 몬스터 이동과, 필요하면 Flame에서 경로를 따라 다시 칠하는 데 쓴다.
  - 길 위에 겹쳐 쓸 흙 텍스처 타일(256×256, 반복 가능) 1장.
- **몬스터 출현 지점:** 위 좌표의 동굴/문 + 길로 이어지는 갈림길. 문 안쪽 보라색 기운 4프레임 반복.
- **장식 배치 금지 구역:** 길과 궁·막사 자리에는 장식을 놓지 않는다(유닛 배치를 가리지 않게). 나무는 맵 가장자리 위주.
- 결과: 레이어별 SVG + 합쳐진 미리보기 1장 + 경로 JSON.

### 2단계 — 궁과 막사
- **궁 (중앙):** 조선 궁궐 정전 느낌, 160×131px. 정면 3/4 시점.
- **막사 6개:** 88×56px. 건물만 보고 병과를 알 수 있게.
  - 창병: 창 거치대가 있는 군영 · 궁병: 망루 + 과녁 · 포수: 화포가 놓인 석조 포루 · 기병: 마구간 · 수군: 선착장 + 판옥선 일부 · 술사: 작은 사당/도량(깃발·부적)
- 각 건물: 기본 1장 + 문이 열리는 애니메이션 3프레임.

### 3단계 — 군졸 · 정병 · 군관 (막사 유닛)
- 6병과 × 3등급 = **18종**, 62×72px (**기병만 80×72px, 말 탄 모습** — 무기 편곤). 묶음: 병과 하나씩(3종) 확인.
- 애니메이션: 걷기 4, 대기 2.

### 4단계 — 장수 (병과별 공용 유닛)
- **6종**, 72×84px. **기병만 96×84px** (말 포함, 앵커는 말 발굽 사이 중앙).
- 애니메이션: 대기 4, 공격 6 (창 찌르기 / 활 쏘기 / 화포 발사 반동 / 말 위 베기 / 환도 베기 / 도술 시전). 투사체 발사 지점은 JSON `events.projectile`에.
- 발밑 병과 색 받침 포함/미포함 두 버전.

### 5단계 — 명장 12명 (인물별 개별 모델링)
병과 색 갑주 + **망토** + 개인 소품 1개. 장수 템플릿을 고쳐 쓰지 않고 인물마다 새로 디자인한다. 묶음: 병과 하나씩(2명). 각 인물마다 먼저 디자인 시트(정면 느낌의 큰 그림 + 실제 크기 + 파츠 구조)를 보여주고 확인받은 뒤 애니메이션을 만든다.

| 병과 | 명장 A | 명장 B |
|---|---|---|
| 창병 | 윤관 (고려, 지원) — 별무반 지휘관 | 척준경 (고려, 공격) — 맹장, 돌격 |
| 궁병 | 이지란 (조선, 공격) — 여진 출신 명궁 | 이성계 (조선, 공격) — 명궁, 훗날 태조 ※영정 주의 |
| 포수 | 문익점 (고려, 지원·경제) — **무기는 총통, 특징 소품은 목화 주머니** | 장영실 (조선, 지원) — 과학 기구 |
| 기병 | 계백 (백제, 공격) — 결사대 | 정년 (신라, 공격) — 창술 기병 |
| 수군 | 장보고 (신라, 지원·경제) — 해상 무역 | 이억기 (조선, 공격) — 전라우수사 |
| 술사 | 원효대사 (신라, 지원) — 승려 | 사명대사 (조선, 지원) — 승병장 |

- 공격 명장: 공격 동작이 장수보다 크고 이펙트가 강함.
- 지원 명장: 공격 + **시전 4프레임**(버프/이속 감소/기절 미정 → 범용 "기운을 퍼뜨리는" 동작).
- 애니메이션: 대기 4, 공격 6, (지원) 시전 4. 상세 창용 **반신 초상** 1장(300×350px 보드 기준, @2x 이상).

### 6단계 — 천명 6명
한 판에 1명만 나오는 최상위: **금빛 오라 + 왕관/상징물**, 80×92px (김유신은 기병이므로 104×92px). 인물별 개별 모델링. 묶음: 2명씩.

| 포수 | 세종 (조선) | 전체 버프형 ※영정 주의 |

| 술사 | 전우치 (조선, 설화적 인물) | 분신·도술 |

- 애니메이션: 대기 4(오라가 숨쉬듯), 공격 8, 등장 연출 6. 상세 창 초상 1장씩.

### 7단계 — 공신 (명장의 각성형)
- 명장 12명 각각: **같은 인물 + 연금색 장식 갑주 + 강화된 오라.** 명장 파츠에 장식 파츠를 덧붙이는 방식.
- 애니메이션: 대기 4, 공격 8, 각성 연출 6.

### 8단계 — 몬스터
걷기 동작이 가장 중요. 일반 40×44px, 보스 72×76px.

### 9단계 — 투사체 · 이펙트
- **투사체:** 화살(궁병), 포탄(포수), 도술 구슬(술사), 물보라/칼바람(수군) — 비행 4 + 타격 4.
- **광역 타격:** 포수 폭발, 수군 물결, 술사 기운 — 3마리를 동시에 맞히는 원형 이펙트. 지름은 사거리 공식 기준으로 맞춘다.
- **상태 효과:** 이속 감소(푸른 서리/족쇄), 기절(머리 위 별), 방어력 감소(금 간 방패), 아군 버프(발밑 금빛 원).

## 제작 방식 (현재)
- **유닛 형태: 슬라임, 2단계 진화** (사용자 선택). 군졸~장수 = 팔다리 없는 기본 슬라임, **등급마다 자라남**, **제미나이가 병과별 완성 그림(성장 라인업 + 장수 3포즈)을 통째로 그림 — 모자·허리띠를 따로 얹는 방식은 '씌운 느낌'이 안 나서 폐기**(군졸 약 46px 아기 물방울 → 정병 54 → 군관 60 → 장수 66px, 양옆에 작은 손) / 명장·천명 = 짧은 팔다리로 두 발로 걷는 위인 슬라임, 인물마다 따로 디자인(천명은 옥빛 수호령). **공신은 명장 슬라임에 각성 파츠를 덧붙이는 방식 — 파츠는 나중에 정함.** 지금은 장수까지 먼저 진행. 위인 슬라임 프롬프트: `제미나이 위인 슬라임 프롬프트.md` (기준: 이순신·세종 슬라임 그림). 몸 색은 병과 색이 기본(이순신 수군=파랑, 세종 포수=보라) — 인물 고유 색으로 바꿀지 미정.
- 군졸~장수 24종은 공통 파츠 시트 6장(기준·몸통/표정·모자·허리띠/갑옷·무기/장비·말)으로 조립하고, 몸 색은 병과 색으로 바꿔 씀. 프롬프트: `제미나이 유닛 프롬프트.md`. 사람 2등신 창병 장수(PR #1)는 시험용.
- **그림은 제미나이**, 자르기·리깅·애니메이션·시트·JSON·배치는 Claude. 프롬프트: `제미나이 소스 프롬프트.md`(캐릭터), `제미나이 맵 프롬프트.md`(맵).
- 제미나이 이미지는 단색 마젠타(#FF00FF) 배경(동굴만 초록). 오른쪽 아래 워터마크는 추출 때 지움.
- 저장소: `mallang-heroes/mallang-heroes.github.io` (Flutter 게임 코드와 같은 저장소, main 푸시 시 Pages 자동 배포). 게임용 결과는 `assets/images`·`assets/data`, 원본·스크립트·문서·미리보기는 `art/`. 작업은 브랜치 + PR로 올림 (PR #1: 맵·창병 장수).
- 아직 할 일: `lib/game/board.dart`를 `assets/data/map-path.json` 경로로 교체, `pubspec.yaml`에 에셋 등록.

## 맵 (제미나이 버전) 수치
- 길: 제미나이 그림을 따라 다시 추출한 **둥근 직사각형 순환로** (예전 육각형 좌표 대신 `assets/map/map-path.json` 사용). 길이 약 3055px, 폭 약 58px.
- 출현 갈림길: x = 1282 일자, 동굴 입구 (1282, 104) → 순환로 합류 (1282, 209). 순환로는 합류점에서 시계 방향으로 시작.
- 동굴: 보드 폭 약 150px, 보라 기운 4프레임(6fps).
- 건물 바닥 가운데(보드): 궁 (702, 432) / 막사 y 372 — 창병 330 · 궁병 436 · 포수 542 · 기병 862 · 수군 968 · 술사 1074. 크기는 `map-path.json`의 buildings.
- 장식 배치와 막는지 여부(blocks)는 `map-path.json`의 decorations.

## 확정된 결정
- 게임 이름: **말랑영웅전** (영문 표기가 필요하면 `Mallang Heroes`).
- 그림체: 시안 B. 외곽선 1.8px(보드) #2A211C, 그늘은 기본색 명도 ×0.72를 오른쪽 아래 테두리에, 광원 왼쪽 위.
- 등급 표시(창병 견본 기준): 군졸 흰옷·전립 / 정병 병과색·붉은 상모 / 군관 어두운 갑주·은 징 / 장수 병과색 받침 / 명장 망토·은 테두리 / 공신 연금 장식·오라 / 천명 금 투구·금 오라.
- (예전 SVG 맵 기준, 제미나이 맵으로 대체됨) 출현 갈림길 `M1264,58 L1264,211.2`.
- 공통 템플릿(0단계 파츠 구조)은 군졸~장수까지만. 위인(명장·천명·공신)은 인물별 개별 모델링.
- 왼쪽 보기는 좌우 반전으로 처리 (왼쪽용 그림 따로 안 만듦). 반전 시 발사 지점 x' = 너비 − x.
- 장식 배치: 길 가장자리에서 45px 안쪽, 나무 주변 70px 안에는 소품을 두지 않는다. 길 바깥은 보드 끝자락에만 듬성듬성.
- 길 바깥도 유닛 배치 공간이다.
- 사거리 반경 = 95 + (사거리 − 1) × 36 (1 → 95px, 1.5 → 113px).
- 제작 방식: 코드(SVG) + 컷아웃 리깅. 파츠 이름·관절은 0단계 `rig-parts.png` 기준.
- 병과 무기는 공통 파츠의 창(spear-*) 대신 `wpn-*`(손과 함께 움직임)·`back-*`(등에 붙음) 파츠로 교체. 궁병: 각궁(앞손) + 동개(등, 화살 깃이 어깨 위로). 포수: 자루 달린 총통(쇠 띠 3개, 두 손) + 허리 뒤 화약 주머니·화승.
- 수군: 환도(앞손, 날을 위로) + 등에 멘 노(어깨 위로 노깃이 보임).
- 술사: 고리 달린 지팡이(앞손) + 부적(뒷손) + 목에 건 염주. (슬라임 버전은 **큰 붓**이 무기 — 사용자 요청)
- 장수 공격 프레임은 무기가 몸 밖으로 뻗어서 여백 캔버스 사용(보병 136×92, 기병 168×92). 앵커는 대기와 같은 발밑 점. events.projectile(투사체 시작점) / events.hit(근접 타격점), @2x 프레임 픽셀.
- 술사는 정병·장수 옷을 밝은 회색(#8C9097) + 먹색 테두리로 (군관 갑주와 구분).
- 기병 장수의 편곤은 말 위에서도 휘두르는 동작이 보이도록 1.7배 크기.
- 기병: 막사 유닛부터 **말 탄 모습, 80×72** (사용자 선택). 무기는 편곤. 말 다리는 대각선 쌍으로 회전, 안장 언치는 병과 색. 앵커는 말 발굽 사이 중앙.
